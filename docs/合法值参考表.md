# 合法值参考表

本表覆盖正式页面中所有可填写的参数和可选择的配置，以及搜索、日期查询与 Debug 文本预览。数值需同时满足格式、范围、启用状态及相关时段或容量约束。

## 输入格式与反馈

| 类型 | 合法格式 | 示例 | 拒绝的输入 |
| --- | --- | --- | --- |
| 整数次数、题量、条数 | ASCII 数字组成的整数，忽略首尾空白，允许前导零 | `20`、` 0020 ` | `+20`、`-1`、`2.0`、`2e1`、`2abc`、整数溢出 |
| 分钟、秒数 | 非负整数或最多一位小数；分隔符可为 `.` 或 `,`；忽略首尾空白 | `10`、`0.1`、`1,5` | `-1`、`+1`、`.5`、`1.`、`1.25`、`1e2`、夹杂文字 |
| 时间端点、每日恢复时间 | 原生 24 小时时间选择器 | `00:00`、`23:59` | `24:00`、无效小时或分钟 |
| 规则组名称 | 首尾空白去除后，最多 20 个 Unicode 字符；允许空名称 | `晚间娱乐`、空名称 | 去除首尾空白后超过 20 个 Unicode 字符 |

输入中保留完整原文，不能把非法内容过滤、截短或夹成另一个合法值。保存失败保留草稿，错误只出现在所属输入下方，使用共用 14sp / 20sp 文字、4dp 上间距及深浅主题的 `error_deep`。框内没有原生错误图标或气泡。继续编辑清除该输入的旧提示。收起规则、其他星期或应用选择的错误使用相应卡片、星期或应用区域的提示入口。

## 规则参数

以下分钟值均精确到 0.1 分钟，即 6 秒。启用规则必须明确填写；全天限时允许明确填写零。关闭规则允许空值或零，已填文字仍需满足合法格式及绝对上界；时段长度关系在规则启用时检查。

| 参数 / 规则 | 启用时的合法值 | 含义及关联限制 | 有意义的示例 |
| --- | --- | --- | --- |
| 全天限时 | 0～720 分钟，含两端 | 每日累计使用额度。零表示不给使用额度；停用由规则开关控制。720 分钟为 12 小时 | `30` 表示每日累计 30 分钟；`0` 表示零额度 |
| 全天限次 | 1～99 次，整数 | 每日允许的打开次数 | `5` 表示每日最多打开 5 次 |
| 全天频率限次：统计窗口 | 0.1～60 分钟，含两端 | 与次数共同定义滚动统计区间 | 窗口 `10`、次数 `3`：10 分钟内最多打开 3 次 |
| 全天频率限次：次数 | 1～99 次，整数 | 限制上述滚动区间内的打开次数 | `3` |
| 全天连续使用提醒：使用 | 0.1～720 分钟，含两端 | 连续累计使用达到阈值后提醒休息 | 使用 `25`、休息 `5` |
| 全天连续使用提醒：休息 | 0.1～720 分钟，含两端 | 独立休息要求；模型不要求休息时长小于使用时长 | 使用 `10`、休息 `15` 同样合法 |
| 时段限时：使用额度 | 大于零，不超过 720 分钟，且不超过时段长度 | 每段独立的累计额度；允许等于时段长度 | 20:00～21:00 可填 `30` 或 `60`，不能填 `60.1` |
| 时段限次：次数 | 1～99 次，整数 | 每段独立的打开次数上限 | 20:00～21:00、`3` 次 |
| 时段连续使用提醒：使用 | 大于零，不超过 720 分钟，且严格小于时段长度 | 窗口恰好为 720 分钟时最高 719.9；超过 720 分钟时可填 720 | 20:00～21:00 最高 `59.9`，不能填 `60` |
| 时段连续使用提醒：休息 | 0.1～720 分钟，含两端 | 独立休息要求；不额外限定为小于使用阈值或时段长度 | 使用 `25`、休息 `5` |
| 时段禁用 | 至少一个合法时段 | 时段内限制使用，不需要额外次数或分钟额度 | 23:00～次日 07:00 |
| 破例放行 | 0.1～719.9 分钟；大于零、严格小于 720 | 必填的临时放行时长 | `10` 表示放行 10 分钟；`720` 无效 |

规则组内应用共享对应额度。单应用使用相同的数值约束；实际规则来源和组优先级遵循当前管控配置。

## 时段、星期和成员

| 项目 | 合法值 / 关系 | 实际含义 |
| --- | --- | --- |
| 时段开始、结束 | 各为 00:00～23:59；内部为 0～1439 分钟 | 不能用 24:00 表示结束 |
| 时段长度 | 开始与结束不同；结束早于开始时跨午夜 | 23:00～01:00 为 120 分钟；相同端点不表示全天 |
| 同类时段 | 不得重叠或重复；边界相邻合法；跨午夜也检查冲突 | 09:00～10:00 与 10:00～11:00 可共存；不同类型按各自时段检查 |
| 已启用的时段规则 | 至少一个有效时段 | 删除全部时段后需补回时段或关闭该规则 |
| 星期 | 每天，或单个星期一～星期日；已保存规则可覆盖多个星期 | 沿用当前逐日保存流程 |
| 规则类型 | 全天限时、全天限次、全天频率限次、全天连续使用提醒、时段限时、时段限次、时段连续使用提醒、时段禁用；可组合启用 | 开启类型才产生对应行为 |
| 规则开关、单独配置 / 规则组启用状态 | 开启 / 关闭 | 关闭保留参数草稿和已有配置 |
| 普通自建组成员 | 至少两个不同应用，来自可管控应用清单 | 重复选择同一应用不能满足两个成员要求 |
| 默认内置组成员 | 使用内置组成员规则，可移除本机已安装成员 | 不套用普通组的至少两个成员要求 |
| 名称为空 | 允许；保存成功后自动命名 | 根据未占用名称生成“规则组 N” |

## 全局设置和挑战

| 参数 | 合法值 | 含义及关联限制 |
| --- | --- | --- |
| 首页用量榜手动条数 | 1～A，整数；A 为最近一次成功扫描并保存的可管控应用数 | 打开表单和保存前均后台只读扫描快照；搜索结果和当日有记录应用数不改变 A |
| 恢复首页默认条数 | 点击“恢复默认” | 删除手动覆盖，重新使用首页实测屏幕容量 |
| 扫描结果缺失 / 空 / 无法读取 | 暂无可保存的手动条数 | 在输入下方说明，保留现有设置；到管控页扫描或刷新后再编辑 |
| 每日恢复时间 | 00:00～23:59 | 全天规则的每日恢复边界 |
| 按压最小时长 | 0.1～3600 秒，含两端 | 不得大于最大时长 |
| 按压最大时长 | 0.1～3600 秒，含两端 | 不得小于最小时长；相等表示固定时长，不相等表示随机区间 |
| 单词词库 | 初中、高中、四级、六级、考研、SAT、托福之一 | 题量上限随所选词库的实际有效容量变化 |
| 单词题量 | 1～N，整数；N 为所选词库实际有效词条数 | 按大小写归一后合并的单词数计容量。切换小词库不截短题量；超容量保留草稿并提示，边界停用增加按钮 |
| 每题最少停留时长 | 0.1～60 秒，含两端 | 精度 0.1 秒；总保底时间为题量 × 每题停留时间 |
| 主题 | 跟随系统 / 白天 / 夜间 | 跟随系统深浅配置，或显式选择浅色、深色 |
| 执行强度 | 随心 / 修心 / 静心 | 首次初始化默认随心，已有配置保留所选强度；内部标识 MORTAL / REPAIR / SEAL；按各档现有交互和保护规则执行 |
| 首页配置引导、每日古诗 | 分别开启 / 关闭 | 分别控制对应区域的可见性 |
| 随心破例放行、动态按钮 | 分别开启 / 关闭 | 放行入口及首屏动态控件选择 |
| 修心破例放行、阻碍页面、再次确认、单词挑战 | 分别开启 / 关闭 | 关闭阻碍页面隐藏挑战子项并保留配置；再次确认决定挑战后步骤，单词开关控制单词挑战参与 |

手动条数可以超过屏幕一次容纳的行数，只要不超过 A；超出屏幕容量的行在列表内部滚动。扫描清单排除 止间自身和未更新的预装系统应用，并按可启动包名去重；容量来自成功提交的结果，详见[应用清单缓存](应用清单缓存说明.md)。

## 实现和验证范围

主要约束入口为 `RuleInputLimits`、`RuleGroupValidator`、`RuleWindowValidation`、`SecondsRange`、`WordChallengeSettings` 和 `UsageRowLimit`。整数原文由 `UnsignedInteger` 解析，时长由 `DecimalDuration` 解析。下方提示通过 `InputFieldLayout`、`InputError`、`RuleValidationFeedback` 与 `SettingsValidation` 复用。

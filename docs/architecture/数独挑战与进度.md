# 数独挑战与进度

数独是修心的第三种可选阻碍页面，默认关闭。启用后与按压、单词一起参与现有会话选择；只剩一种开启时不能关闭最后一个开关。每次完成 9×9 一局，设置摘要只显示简单、中级或困难，点击后通过设置底部弹窗选择。数字键为 3×3 九键，没有独立清除键。选中可填写格后，点击与当前格不同的数字填入或替换，点击相同数字清空，不要求快速双击；切换格子后按新格的当前值判断。给定数字不可选中或编辑，点击不会夺取原有选择，键盘也不聚焦给定格；行、列、宫重复时标记冲突。

## 保存与恢复

正式进度位于应用私有文件 `files/sudoku_progress.json`，保存一局全局进度，不按应用或临时拦截会话分散。字段为 `attempt`、`revision`、`clues`、`values`、`completed_session`、`difficulty`、`entry_id`。保存完整题面，恢复不依赖以后题目工厂的实现。已有记录缺少难度时按简单标记；缺少进入标识时使用空值，已有填写仍优先恢复。

尚未填写时，退出再进会创建不同题面；只选中格子不算开始。原次进入内的旋转、主题切换和规则复查仍恢复原题。成功填写过的未完成局无论哪个应用触发都继续保留，即使后来全部清空，也由已提交版本记录识别为开始。选择格子存入页面 Bundle，恢复时丢弃指向给定格或另一题面的选择；所有填写、替换与清空存入文件，清空使用原有的数字 `0` 编码。每次编辑按尝试身份和版本复核后提交，完成标记与最后一格一起落盘；确认保存成功后才刷新界面及向状态机发送 `CHALLENGE_COMPLETED`。旧页面不能覆盖更新的棋盘或新的一局。

难度保存在 `global_settings.sudoku_difficulty`，同时进入交互设置和 Bundle 快照。读取已开始的未完成局时优先使用该局自己的难度与棋盘，修改设置不会重新出题；新局才按新会话选择创建。难度选择取消不保存，确认后设置摘要只显示所选难度。

完成后，同一拦截页面重建保留终盘。普通退出或继续的结果保存成功后，协调层将该完成局标记为已结束；下一次挑战生成不同题面，即使运行层复用了拦截身份也会换题。未完成局不受这个结束操作影响。新拦截身份遇到已完成局同样创建下一局。

文件读取或写入失败时保留原记录，提供重试与退出，不静默生成新题。写入在后台执行，页面暂停不取消已经排队的保存；离开前台的回调不触发导航。页面不能直接放行，休息与其他规则仍由原状态机和运行层判断。

Debug 预览和独立页面样例只用内存进度及 Bundle，显式 `persistentProgress` 标记与主句持久化开关分开。正式单词挑战已接入独立的 `word_progress.json`，与数独共用进入边界，详见[挑战进度与重新进入](挑战进度与重新进入.md)。

## 题目与界面

题目工厂按难度选择三套独立基础题面：简单预填更多数字，中级使用基础题面，困难使用更稀疏的题面。每套题面均作数字置换和转置，相同难度及种子产生相同题目；新局独立生成身份并避免与上一题题面相同。三档题面的唯一解和空格数量递增由独立回溯解数器的回归用例约束，该用例本次尚未执行。

普通状态只显示完整棋盘、数字键和退出按钮，没有主句及其占位。数独页左右留白为 12dp，格子基础尺寸为 40dp，棋盘数字使用 20sp，九键数字使用 18sp，通过独立文字样式复用全局字号与主题色，并去掉额外字体上下留白。三行三列的数字键区基础宽度为 168dp，默认字体下按钮为 48dp 方形，四周各留 4dp 间距；竖排时居中向右偏移 12dp，并限制在可见范围内。棋盘和键区按可用宽高共同等比缩小，完整展示且无滚动。宽矮空间可左右排列，触控随视图矩阵转换。给定数字、选中状态、重复冲突与读屏说明复用深浅主题，夜间普通数字跟随全局柔和灰白文字。保存失败时显示系统 Toast 和重试入口。

解完并保存成功后进入 `SUDOKU_COMPLETED` 并锁定输入。数字键先用 180ms 淡出并下移 8dp；布局预留隐藏的继续按钮高度，终盘在 260ms 内上移到内容区顶部；随后完成语句用 200ms 淡入，继续按钮同步浮出并在动画结束后开放点击。终盘与语句按最终可用宽高一起缩放，语句位于棋盘下方、按钮上方，基础间距 16dp，不引入滚动。动画逐帧只修改绘制变换；重新布局时更新终点。

完成语句由独立 XML 数组 `interception_sudoku_completions` 管理，使用已经保存的随机局身份稳定选句，同局恢复一致，新局重新选取，不新增存储字段。开启再次确认时，点击继续才进入 `FINAL_CONFIRM`；关闭时由原有放行设置决定继续结果。暂停、系统关闭动画或页面重建时直接显示终盘、完成语句和继续按钮。真实休息已满足时仍保留原运行层的恢复判定。

## 验证范围

新增 `SudokuBoardTest`、`SudokuProgressTest`、`SudokuProgressStoreTest`、`SudokuPageTest`。`RepairContinuationTest` 扩展到三种挑战，数独通过屏幕题面独立求解、点击真实控件完成；夹具保存并恢复正式进度文件。挑战开关、文案分类及通用目录用例同步更新。

本次仅做源码、XML、资源引用和差异的静态核对，未运行测试、编译、Lint 或真机操作。回归源码覆盖三档选题、难度保存与取消、未完成局保留、给定格不可选、九键填入／替换／再次点击清空及恢复，并检查答题无主句、终盘上移、同局完成语句恢复、窄屏与宽矮空间的最终边界、前后台恢复及主动进入反问。动画中途误触、实际屏幕和大字体下的过渡效果、缩放后点击与深浅色操作仍待真机验收。

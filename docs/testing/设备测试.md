# 设备测试

[返回测试入口](README.md)。源码根目录为 `app/src/androidTest/java/github/vhoom/zhijian/`，共54个测试类、320个 `@Test` 方法。共享夹具不计入数量。本次运行结果见[前台窗口修复验证](前台窗口修复验证.md)。此目录依赖 Android 运行时，即使只测量独立控件，也应由 AndroidJUnitRunner 执行。

## 运行与筛选

```powershell
.\gradlew.bat :app:assembleDebugAndroidTest
.\gradlew.bat :app:connectedDebugAndroidTest "-Pandroid.testInstrumentationRunnerArguments.class=github.vhoom.zhijian.ui.binder.DashboardBinderTest"
.\gradlew.bat :app:connectedDebugAndroidTest "-Pandroid.testInstrumentationRunnerArguments.class=github.vhoom.zhijian.ui.component.navigation.PullRefreshLayoutTest#refreshHintStartsHiddenAndCancelledDragDoesNotRefresh"
```

`assembleDebugAndroidTest` 只编译测试 APK；`connectedDebugAndroidTest` 会构建、安装并执行所选设备用例。筛选使用当前完整包名，默认执行全部设备用例。报告目录为 `app/build/reports/androidTests/connected/`，编译成功不等于设备断言通过。

## 运行条件与设备影响

使用 Android 10+ 的独立测试设备或模拟器，保持屏幕解锁且允许页面进入前台。真实服务用例需要系统支持 UiAutomation 修改相关授权；前台与 UsageEvents 用例需要测试 APK 的目标页面能够被启动。安装的应用与测试 APK 应来自同一次 Debug 构建。

独立资源和组件用例不主动启用权限。页面与偏好用例可能打开实际 Activity、暂存设置或创建测试策略，依靠原有 finally / @After 恢复。数据库用例既有独立数据库，也有使用应用待处理存储的集成路径，不能把整套设备测试理解为只读操作。

`ProtectionDeviceSession`、`GroupedContinuousUsageTest` 和 `InterruptionRuntimeTest` 会临时修改规则或使用访问 AppOps；其中真实无障碍链路还会修改安全设置并连接服务。`ProtectionDeviceSession` 和分组用量会话在修改持久状态前登记恢复计划，普通初始化/清理异常不会阻止其他步骤继续尝试；原始错误与恢复错误会一起报告。进程强制终止、系统拒绝操作等情况仍可能导致状态没有成功恢复。运行前后应检查所用测试设备的授权与规则状态；本次检查结果见[真机验证](真机验证.md)。

`StorageIntegrationTest.largeHistoryUsesCompositeIndexAndReportsDeviceTimings` 记录设备时序并校验索引，结果受设备影响，不作为通用性能基准。首屏、挑战和主题用例验证各自声明的断言；没有截图或布局断言的状态仍需另行观察。

## 条件执行与覆盖边界

- `ForegroundEvaluationTest.acceptedBackOnlyWithoutLeavingTargetFallsBackToPage` 在当前非静心且已有用户限制时通过 `Assume` 跳过，避免测试强行切换档位。报告必须保留跳过状态；这不是通过该回归。
- `RuleGroupingTest.captureReminderScreenshots` 与 `WordPresentationTest.captureIfRequested` 是截图辅助函数。未设置 `ruleScreenshots` / `zhijian.captureUi` 时只跳过截图导出，主测试的行为断言仍执行。
- `GroupedContinuousUsageTest` 的 `groupCleanupIds` 是显式清理入口；未传参数时仅不执行这个 `@BeforeClass` 恢复动作，正常测试仍运行。
- `ForegroundEvaluationTest` 使用反射准备竞争状态和记录启动 Intent，可以验证服务方法分支；它不证明 Android 已连接真实服务或窗口已经显示。真实服务入口另见 `GroupedInterceptionServiceTest`、`InterceptionReentryTest` 与 `RepairContinuationTest`。
- 预览用例有意验证预览隔离。证明生产放行或休息恢复时，应使用正式会话与存储路径，不能只看到预览页面关闭就认为完成了回归。

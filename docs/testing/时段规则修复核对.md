# 时段、休息与配置更替修复核对

修复位于`bug/fix-time-rule`，基线为已对齐远程的`main`。以下描述当前实现和回归源码的断言范围；本次构建、本地及设备测试、Lint和安装结果另见[前台窗口修复验证](前台窗口修复验证.md)，不能仅凭下表源码入口推断设备场景均已通过。

## 用户操作与预期效果

| 用户操作 | 当前实现 | 回归源码 |
| --- | --- | --- |
| 本轮休息三分钟，未完成前调大到十分钟，再休息满原三分钟 | 原三分钟不能解除；立即提高本轮要求，已休息进度保留。连续非使用超过五分钟仍可结束本轮。 | `ContinuousUsageCycleTest`、`ReminderRestPolicyTest` |
| 本轮未完成时调小休息，或先调大再调小 | 保留本轮已经生效的较大要求；本轮完成后下一轮采用当前小值。 | `ContinuousUsageCycleTest`、`ReminderRestPolicyTest` |
| 非使用恰好五分钟／超过五分钟，或已经满足较短的本轮休息 | 所有作用域统一使用“严格超过五分钟，或满足本轮有效休息”条件；短休息之间重新使用会打断连续非使用，不能拼接。 | `ContinuousUsageCycleTest`、`ReminderRestPolicyTest` |
| 已完成修心挑战并停在再次确认页，只改组名或原样保存 | 名称正常更新，规则版本保持，已完成挑战及阶段保留；等价七日参数展开同样保留版本。 | `RuleConfigurationComparisonTest`、`StorageIntegrationTest` |
| 同时达到限时、限次，关闭临时放行，完成挑战并继续 | 本次应用持续前台访问期间全部禁用不再打断；后续连续使用提醒仍生效。真实离开、桌面或锁屏后再进入重新检查，配置或档位改变也重新判定。 | `BlockVisitContinuationTest`、`BlockContinuationStoreTest` |
| 点击继续后在原应用弹出、收起带应用图标的输入法，或出现其他应用浮层 | 键盘与未改变实际前台的浮层不结束原访问或清除继续确认；输入法设置 Activity、桌面及其他应用的真实前台仍结束确认。模糊窗口后台核实，期间不以旧计算结果弹页，旧核实回调不覆盖新前台。 | `ForegroundWindowContinuationTest` |

| 原09:00～10:00提醒已继续，改成11:00～12:00，休息未满而继续使用 | 旧使用统计最迟在原终点或保存时刻中较早者封口，不在新时段外继续累计；旧休息保留，新窗口独立统计、保存休息，旧确认不抵扣新用量。 | `ReminderScheduleTest`、`PendingInterceptionStoreTest`、`ReminderThresholdRuntimeTest` |
| 点击继续后保存期间发生页面重建 | 正式及调试入口共十个页面固定竖屏；其他配置重建继续观察原任务，保存页保留出口。进程恢复以相同提交身份及确认时钟重放，成功并恢复前台后导航，不重新加载已完成挑战或延长授权。 | `InterceptionSubmissionLifecycleTest` |

## 本次实际验证

手机导出的 `止间-diagnostics-20261117-101343.zip` 记录了修复前的重复拦截。北京时间2026年11月17日00:39:50.815继续确认已应用，00:39:51.195允许B站使用，00:39:51.573将搜狗输入法记录为前台，00:39:52.094恢复B站，00:39:52.407再次命中同一时段禁用，00:39:52.557窗口确认显示。00:37与00:39的多组记录具有相同链路。代码核对表明，原过滤以应用启动入口判断浮层，导致有图标的输入法被当作真实离开并清除确认。

当前修复使用组件元数据及后台系统前台查询区分窗口，保留既有无障碍事件与不读取窗口内容的权限范围。10个设备回归方法在本次构建和安装的版本中全部通过，正式服务事件入口和独立偏好路径验证访问确认，元数据和后台查询结果采用可控输入；厂商输入法仍需手动验收。

已执行 Git 差异空白检查，静态核对 Java 内部类型导入、括号配对和维护日期；解析正式与调试 Manifest XML，并核对十个页面的竖屏声明及 Android 16 大屏保留方向限制的兼容属性。测试数量只按源码中的 `@Test` 声明统计，不代表通过数量。

本次458个本地方法及69个相关设备方法通过，并验证三种挑战页静止、操作和完成后停留累计同一次休息，以及提醒阈值和窗口端点更替后的旧休息保留。其余设备场景、完整厂商窗口延迟、保存中系统回收和大屏方向仍需单独验收，详见本次报告。历史测试报告不能替代本次结果。

# UI 设计规范

本文描述当前 Android Java/XML 界面的共用规范。首页、管控、规则编辑、设置、关于、诊断和拦截页面使用同一套文字、表面和状态资源。页面行为见[界面与配置说明](界面与配置说明.md)，拦截路由见[拦截架构设计](architecture/拦截架构设计.md)。

## 资源入口

| 内容 | 唯一配置入口 |
| --- | --- |
| 字体名称、弹窗遮罩及底部弹窗高度比例 | `app/src/main/res/values/ui_tokens.xml` |
| 字号、行高、间距、圆角和窗口宽度 | `values/dimens.xml` |
| 文字层级 | `values/text_appearances.xml` |
| 通用文本、卡片、按钮、输入框、开关 | `values/widgets.xml` |
| 设置行和步进器 | `values/settings_widgets.xml`、`values/settings_dimens.xml` |
| 弹窗标题、按钮及日期/时间控件 | `values/dialog_styles.xml` |
| 浅色、深色语义色 | `values/colors.xml`、`values-night/colors.xml` |
| 主题与系统控件接线 | `values/themes.xml`、`values-night/themes.xml` |
| 拦截按钮的主题角色与样式 | `values/interception_colors.xml`、`values/interception_styles.xml` |

表中省略的资源前缀均为 `app/src/main/res/`。`rule_editor.xml`、`word_colors.xml` 和 `interception_colors.xml` 使用全局资源别名；拦截表面、文字和边框随全局深浅色资源解析，不单独维护固定色板。尺寸用 dp，文字及行高用 sp，随系统字体设置缩放。

## 字体与文字层级

普通界面使用 Android `sans-serif`，中等字重使用 `sans-serif-medium`；不打包额外字体。中文由系统字体回退提供，具体字形随系统和 ROM 变化。通用文字字距为 0，不额外压缩汉字间距。

| 用途 | 字号 / 行高 | 字体与字重 | 样式 |
| --- | --- | --- | --- |
| 首页当前页标题、强度名称 | 24sp / 32sp | sans-serif，粗体 | `Text.App.Title` / `DisplayMd` |
| 弹窗和底部弹窗标题 | 20sp / 28sp | sans-serif-medium | `Text.App.DialogTitle` |
| 普通页面顶栏标题 | 18sp / 28sp | sans-serif，粗体 | `Text.App.Heading` |
| 设置、规则、列表主标题 | 16sp / 24sp | sans-serif-medium | `Text.App.Strong` |
| 正文、输入值、对话框消息 | 16sp / 24sp | sans-serif，常规 | `Text.App.Body` / `BodyMd` |
| 页面操作按钮 | 16sp / 24sp | sans-serif-medium | `ButtonLg` |
| 顶栏操作、弹窗按钮、紧凑操作 | 14sp / 20sp | sans-serif-medium | `ButtonMd` |
| 设置分区标题、规则分区标题 | 14sp / 20sp | sans-serif-medium | `Text.App.SectionLabel` |
| 说明、空状态、错误、答题反馈 | 14sp / 20sp | sans-serif，常规 | `Text.App.Supporting` / `Text.App.Error` |
| 日期星期、数量和状态等辅助信息 | 12sp / 16sp | sans-serif，常规 | `Text.App.Caption` |
| 拦截主句、全屏保存状态 | 24sp / 36sp | sans-serif，常规 | `Text.App.InterceptionHero` |
| 协议正文 | 16sp / 28sp | sans-serif，常规 | `Text.App.Document` |
| 作者书信 | 16sp / 32sp | serif，常规 | `Text.App.Letter` |
| 诊断日志 | 12sp / 20sp | monospace | 诊断正文布局 |

首页未选中的页签使用 14sp / 20sp，当前页使用 24sp / 32sp；较小页签的下沉和淡化表达导航层级。单词选项正文使用 16sp / 24sp，词性片段保留 serif 斜体。按压挑战的单行引导从12、14、16sp三档中选择适合宽度的字号。日期/时间选择器的数字表盘和日期格使用原生控件排版，标题、外壳、状态色及操作按钮接入共用主题。

拦截主操作沿用 16sp 中等字重，次操作和单词选项使用 16sp 常规字重，Debug 预览入口使用 14sp 常规字重及正文色。主句保留 24sp 常规字重，辅助说明、答题反馈和倒计时继续使用共用文字层级，通过表面、字号和字重表达层级。

文本允许自然换行；应用列表名称和标签在有限宽度下可单行省略，读屏描述保留完整信息。长协议、长弹窗正文和拦截主句可滚动。单词题干保留可横向滚动的一行排版。

作者信末尾的 `{{app_name}}的开发者` 署名与时间文字“每天”分为两行，一起右对齐，沿用书信字体、字号和文字色。阅读页面将最后两个非空行设为署名与时间段落，保留原文换行与应用名称替换。

首页强度卡片的模式名与诗句复用 `view_strength_stage.xml`，区域采用 144dp 最小高度，长诗句和较大字体按内容自然增高。模式名与诗句之间至少留 8dp，正文保持 16sp / 24sp，不限定行数或缩小字号；超出首屏的内容由首页外层滚动容器承载。

首页诗句按手机本地日历日期固定，每天首次读取时随机选取并保存正文，当天刷新、返回及重启均复用。日期变化后的首次读取换句，资源有其他正文时避开上次诗句。Debug 长度预览继续使用独立随机入口，不读写每日缓存。

首页使用统计的应用列表按可用高度容纳完整行，达到容量后在组件内部纵向滚动，使用平台滚动条。总时长和日期保持在列表滚动区域外；行高继续复用当前文字、图标和间距资源，并随字体缩放重新计算容量。

首页配置引导共五项：第一行展示无障碍与使用情况访问，第二行并排展示电源设置与自启动，第三行由后台运行使用完整行宽。设置页按无障碍、使用情况访问、电源设置、后台运行、自启动排列为五行列表。每项状态独立显示，完整文字同时进入读屏描述；无法统一检测的厂商配置保持“手动检查”。标题和状态允许随可用宽度自然换行。

## 间距、尺寸和边界

间距档位为 4、8、12、16、24、32、48、64dp，分别对应 `space_xxs` 到 `space_4xl`。

| 元素 | 当前尺寸 |
| --- | --- |
| 普通页面左右留白 | 16dp |
| 卡片内边距、相邻主卡片间距 | 16dp |
| 设置行 | 左右 16dp、上下 12dp，最小高度 56dp |
| 标题与说明 | 4dp |
| 控件、标签之间 | 按层级使用 8dp 或 12dp |
| 分组标题前留白 | 24dp；规则编辑分区采用 12dp |
| 顶栏 | 最小高度 56dp，内容需要时增长 |
| 普通按钮、输入框、独立操作点击区 | 最小高度 48dp |
| 应用清单刷新按钮 | 数量行开头的 18dp 图标，与文字间隔 4dp；触摸代理保留 48×48dp 点击区 |
| 输入框 | 左右 12dp、上下 8dp；时间框和步进值按结构居中 |
| 普通按钮 | 左右 16dp、上下 8dp |
| 拦截内容 | 左右及底部 24dp，顶部 32dp，另叠加系统安全区 |
| 拦截操作 | 最小高度 56dp，内边距 16dp；首屏按钮/滑块最小高度 64dp |
| 单词选项 | 最小高度 72dp，内边距 16dp，两列间距 12dp |
| 开关 | 轨道 52 × 30dp，圆形滑块 26dp，触控高度至少 48dp |
| 普通应用图标 / 规则组成员图标 | 28dp / 24dp |
| 边框和分隔线 | 1dp |

管控中心顶部留 8dp，数量行与搜索框间隔 8dp，并保持至少 48dp 宽高。刷新按钮位于数量行开头，布局宽度与图标同为 18dp，水平内边距为 0；其后留 4dp，再显示使用 `Text.App.Caption` 的“共 X 个可管控应用”。整行按内容宽度排列，窄屏和较大字体时数量文字可换行；透明数量行通过触摸代理保留按钮至少 48×48dp 的点击范围，左右布局同步镜像。刷新箭头与配置图标采用相同的 1.6 视口单位圆角线条，尺寸由 `action_icon_size` 统一为 18dp。按钮复用 `Widget.App.IconButton` 和页面操作入口的无边框水波纹，默认无边框和底色；按压色跟随 `control_highlight`，图标通过 `button_secondary_text` 复用深浅色 `ink` 与 `disabled_text` 状态，并提供读屏说明。

| 圆角用途 | 半径 | 资源 |
| --- | --- | --- |
| 主卡片、设置卡片、阅读纸面 | 12dp | `bg_card` |
| 子分组、时段块 | 8dp | `bg_subsection` |
| 输入框、页面按钮、文本操作反馈 | 8dp | `bg_field`、`bg_button_*` |
| 普通弹窗 | 16dp | `bg_dialog` |
| 底部弹窗顶部 | 16dp | `bg_settings_sheet` |
| 日期与星期选中块 | 12dp | `bg_usage_date`、`bg_weekday_choice` |
| 标签、强度档位选中态 | 100dp胶囊半径，按实际高度裁定 | `bg_tag`、`bg_pill_level` |
| 开关轨道 / 滑块 | 15dp / 13dp | `bg_switch_track`、`bg_switch_thumb` |
| 拦截拖动滑块 | 24dp圆形半径 | `SlideActionView` |

单应用和规则组配置页共用一个“提醒规则”分区，八张规则卡按全天限时、全天限次、全天频率限次、全天连续使用提醒、时段限时、时段限次、时段连续使用提醒、时段禁用排序。规则组在分区标题下显示“同组内所有配置共享额度”，复用 `Text.App.Caption` 的12sp字号、16sp行高和 `rule_text_secondary` 语义色，标题与说明间距4dp，说明与首张规则卡间距12dp，允许随可用宽度自然换行。星期选择位于分区上方，破例放行位于下方；当前编辑星期使用 `rule_primary_soft` 浅绿底色和 `rule_primary` 描边，未保存规则的星期选中后也显示底色。已保存星期继续使用绿色文字与底色，当前选择由描边独立标记；深色模式复用对应夜间语义色。分区标题继续使用 `Text.App.SectionLabel.RuleEditor` 并标记为读屏标题，卡片及参数沿用现有深浅色资源。

规则卡片使用 `fg_card_feedback` 共用前景点击反馈，水波纹由 `radius_lg` 的 12dp 圆角遮罩限定在整张父卡片内，与 `bg_card` 的边界一致，颜色复用深浅主题的 `control_highlight`。父级通过 `addStatesFromChildren` 接收标题行按下状态，前景包含卡片内边距及已展开内容；标题行不再叠加独立水波纹。单应用和规则组使用同一个卡片布局，原有点击范围、开关切换及参数输入保持不变，父卡片不新增点击处理。

单项参数容器保持透明，不叠加背景或容器内边距；全天限时、全天限次的输入行直接放在主卡片内，与标题留12dp间距。连续提醒和时段规则包含多个参数或操作，使用 `bg_rule_panel` 浅灰面板、12dp圆角和10dp内边距，与标题留12dp间距。时段限时将开始时间、结束时间、使用额度和删除按钮放在同一条白色行内，额度与结束时间间距8dp，窄屏或大字体时整行横向滚动。时段连续提醒先显示包含“开始／结束”和删除操作的白色时间行，下方以 `view_rule_usage_rest.xml` 并排展示“使用／休息”，单个参数不再包裹白色子卡，行间和双参数间距8dp。时间行使用 `bg_rule_parameter`、8dp圆角、1dp语义描边及10dp水平内边距，垂直空间由触控容器提供；主卡继续采用现有16dp内边距和12dp圆角。多个时段之间留16dp，“添加时段”的整行虚线按钮位于同一浅灰面板内，文字12sp，上下内边距8dp。全天连续提醒显示并排参数，时段禁用只显示时间行。

全天频率限次在同一浅灰面板内仅提供一条“X 分钟内最多打开 N 次”配置，分钟窗口和整数次数分别使用既有紧凑输入框。时段限次复用时段限时的单行结构，将时长额度改为次数，每段独立设置。三种限次输入框不显示范围提示；所有手动规则输入在保存或确认应用时统一校验，编辑时保留空值、超范围和格式未完成的原文。输入框不通过长度或数字过滤器截断粘贴内容，数字键盘保持不变；继续编辑时清除上一轮错误。具体上界见[规则输入校验](界面与配置说明.md#手动输入校验)。

规则参数的标签、单位、时间与数字统一12sp、16sp行高，参数文字由 `Text.App.RuleParameter` 共用，行内数字由 `Widget.App.Field.RuleInline` 共用。数字保留中等字重，标签和单位沿用全局正文色；规则标题与说明继续保留16sp、14sp层级。全天限时、限次和破例放行的行内输入值与单位也采用12sp。时间框最小62×30dp，使用与休息数字框最小46×28dp，采用 `bg_rule_input` 浅灰矩形表面、1dp语义描边、6dp圆角和四周4dp内边距；时间标签与框间距6dp。`CompactRuleField` 按最小宽度与当前最长行宽加复合内边距的较大值显示，内容或字体增大时扩展，空值按提示文字测量；下方错误提示不参与输入框宽度计算。透明外层以触摸代理保留至少48×48dp点击区域。时段时间行与双卡共用横向滚动入口，全天参数使用独立滚动入口；窄屏或大字体保留同一行的完整参数。跨午夜的结束框保留“次日”和时间两行。数字解析、草稿保存、保存校验、读屏描述和时间选择器继续使用已有实现。

破例放行的时长输入框也复用 `Widget.App.Field.RuleCompact` 和 `CompactRuleField`，最小46×28dp、12sp数字、6dp圆角、浅灰表面与细描边，和分钟单位间距4dp。单应用及规则组入口都保留透明触控容器，输入内容超出最小宽度时自动扩展。

全天限时、全天限次使用同款最小46×28dp数字框；规则组名称通过 `Widget.App.Field.RuleText` 复用浅灰表面、6dp圆角、12sp字体与28dp最小高度，名称保留整行宽度和10dp水平内边距。全部输入通过透明容器保留至少48dp触控高度。`RuleInputFocus` 统一处理点击输入区域外和键盘完成后的失焦、收起键盘，切换输入框时保留键盘。外部触摸继续按原生流程处理按钮、开关与滚动，输入变化仍由既有草稿监听保存。

修心“阻碍页面”的子项放在父卡片内部，左右及底部留 12dp，使用次级表面、1dp 描边和 8dp 圆角。边界、缩进和整体显隐共同表达从属关系。按压挑战、单词风暴和数独挑战使用同款独立开关，摘要行可打开各自参数设置。首次默认开启阻碍页面，仅按压挑战开启，按压随机 50～75 秒；单词默认关闭，参数仍为 17 题、每题至少 2 秒及初中词库。数独默认关闭、难度简单，摘要只显示当前难度“简单”“中级”或“困难”，点击后通过 `SettingsBottomSheet` 选择并确认；已开始的未完成局保留原题面，难度变更从新局生效。已保存的用户设置优先于这些默认值。阻碍页面开启且只剩一个挑战时，该挑战开关保持选中并限制操作，轨道和滑块沿用正常开启颜色；读屏描述与工具提示说明至少保留一种挑战。其他开关仍可开启，开启后解除锁定。关闭总开关隐藏子项并保留挑战选择及参数。

数独答题阶段显示完整棋盘、九个数字按钮和底部退出操作，顶部不显示主句也不预留空间。页面左右留白缩至 12dp，格子采用 40dp 基础尺寸，棋盘数字使用 20sp，九键数字使用 18sp，分别由 `TextAppearance.App.SudokuCell` 和 `TextAppearance.App.SudokuKey` 复用全局字号与文字色；两者去掉额外字体上下留白并居中。九键按 3×3 排列，基础宽度 168dp，按钮在默认字体下为 48dp 方形，四周各留 4dp 间距，竖排时居中向右偏移 12dp；没有独立清除键，选中可填写格后点击数字填入，点击与当前格相同的数字清空，点击其他数字替换，不要求快速双击。填写、替换和清空均保存进度，数字按钮的读屏说明同步表示填入或清空。棋盘与键区之间留 8dp，`SudokuPanelLayout` 根据可用宽高整体等比缩小，宽矮空间可左右排列，不出现滚动。显示与触控位置随整体比例变化。给定数字加粗并使用次级表面，只保留读屏说明，不接受点击选择或键盘聚焦，也不改变当前可填写格的选中状态；选中格沿用绿色描边，冲突使用错误色与读屏说明。保存失败由系统 Toast 提示并显示重试按钮。详见[数独挑战与进度](architecture/数独挑战与进度.md)。

数独保存完成后先锁定输入，九键用 180ms 淡出并下移 8dp；继续按钮先隐藏占位，终盘用 260ms 上移，随后在棋盘下方、按钮上方用 200ms 淡入本局完成语句，继续按钮同步浮出。终盘与语句按最终可用空间共同缩放，基础间距 16dp，语句居中并复用 24sp／36sp 的主句文字层级。完成语句在独立 XML 数组中维护，按已保存的随机局身份稳定选取。开启再次确认时，点击该按钮才进入反问页；关闭时沿用原继续结果。后台切换、系统关闭动画和页面重建均直接显示最终状态，动画未结束时不会出现可误触的继续操作。

## 颜色与深浅色

黑白灰构成页面和操作的主色，绿色表示启用及已配置状态；链接、警示和错误使用各自语义色。品牌图标的固定深蓝不作为页面强调色。

白天页面采用柔和灰白 `#ECEDEB`，卡片采用 `#F3F3F0`，主文字与正文分别为深灰 `#353B42`、`#555D66`。夜间页面采用深灰 `#1B1E22`，卡片为 `#23272D`，主要文字为柔和灰白 `#CDD2D8`，正文为 `#AEB5BE`，辅助文字为 `#969FA9`。两套配色都通过表面和文字的亮度层级区分内容；文字资源与主操作表面分别管理，页面、弹窗、规则及拦截组件通过全局语义色和别名统一取色。

## 弹窗与提示

`ui/component/dialog/AppDialogs` 创建原生 `AlertDialog.Builder`，`AppDialogs.show(dialog)` 展示先创建的确认框、日期或时间选择器。普通弹窗宽度为窗口宽度减去两侧 16dp，最大 480dp；内容水平内边距 24dp，圆角 16dp，遮罩 40%。确认、取消和恢复默认采用统一的 14sp 文本按钮。长内容交给原生滚动和按钮布局处理，输入校验监听保留，校验失败时不关闭草稿。

全部手动输入的错误使用 InputFieldLayout 与 InputError 绑定到控件下方，复用 Text.App.InputError 的14sp文字、20sp行高、4dp上间距、error_deep 深浅语义色和 polite 读屏区域。紧凑控件由第一项触控容器决定宽度，提示在该宽度内换行，不扩大数字框；名称及主页条数保持整行宽度。输入正文不使用原生错误图标、气泡或 setError()。RuleValidationFeedback 立即显示所属提示、定位输入并滚动整个输入与提示区域，数值错误不再打开独立校验对话框。收起规则和其他星期继续通过所属卡片或星期入口定位，保留当前草稿；页面销毁及后续定位使旧焦点回调失效。

每个 InputFieldLayout 固定包含输入区域和下方 TextView 两个直接子视图，通过 errorCaption() 提供自己的提示。绑定、单项清理和整表清理按所属容器定位，不要求所有提示使用相同 ID。同一布局内多个提示必须使用独立 ID；秒数区间、单词挑战、时段端点和频率参数分别按字段命名，避免 DuplicateIds 和错误绑定。提示位置、宽度及主题样式沿用共用资源。

遮罩值在 `ui_tokens.xml` 中以 `type="dimen" format="float"` 声明为 `0.4`，深浅色主题的 `android:backgroundDimAmount` 与两个弹窗工厂共用 `dialog_dim_amount`。这里的 `dimen` 只是资源分类，Java 使用 `Resources.getFloat()` 读取；不能写成百分比或带 `dp` 的尺寸，否则系统创建窗口时的 `TypedArray.getFloat()` 会抛出数值转换异常。底部弹窗的 `sheet_max_height` 表示高度比例，继续使用 `fraction` 和 `getFraction()`。

档位切换、规则删除/重置、放弃修改、权限引导、主题选择、首页条数、诊断清空和预览菜单均使用该入口。应用多选弹窗内容区统一为 24dp 水平留白，列表最高 360dp，窗口不足时收缩列表并保留滚动。

五项配置入口直接使用共用原生说明弹窗，各说明保持取消、前往设置按钮；无障碍说明另有打开应用信息按钮。开发者页面复用正式配置布局、文字和说明工厂，可切换样例、布局与首页展开状态；预览操作继续使用 Android 原生 Toast，深浅色跟随页面主题。

开发者页面提供诗句长度预览，多行输入实时绑定到首页共用区域；输入框最多显示六行后内部滚动，不限制预览正文行数。随机和最长诗句操作直接读取当前 XML，字符数按 Unicode 字符计算，显示行数在实际排版后更新。自定义文本仅用于 Debug 页面，并在页面重建后恢复。

`SettingsBottomSheet` 用于挑战参数及词库设置：宽度不超过 600dp，高度不超过窗口的 80%，左右留白 16dp，顶部 12dp，底部 24dp 加导航安全区。标题 20sp，完成和恢复默认 14sp；使用 `canvas` 托住内部卡片，窄窗口全宽显示，大窗口居中靠底，键盘出现时调整可用区域。

普通说明和空状态采用 14sp 正文色；就地错误采用 14sp 错误色并通过 `polite` 读屏区域播报。错误只出现在所属输入下方，继续编辑清除该输入旧提示；设置参数和规则参数复用同一提示组件。权限组合不足时使用常驻浅警示卡片，说明与操作同时可见。

保存成功、链接不可用和预览结果等短反馈使用 `Toast.makeText()`；存储失败和静心保护提示使用较长时长。所有文字来自字符串资源。Toast、系统权限页面及文件选择器的具体外观由 Android/ROM 绘制，不伪造应用内副本，也不依赖覆盖系统字体或位置。

## 动画与维护

阻碍子项展开/收起使用 220ms 的高度变化与淡入淡出；初次加载和恢复状态直接展示。首页翻页使用 180ms，日期吸附使用 160ms。系统禁用动画时直接完成状态切换。关闭设置或销毁页面时结束相关动画，隐藏子项不参与读屏导航。

应用清单读取或保存期间只旋转刷新按钮中的箭头，点击反馈保持静止，每圈 900ms；同时禁用重复点击，采用共用禁用颜色，并同步更新读屏说明。只有管控页处于前台时运行动画，隐藏、离开前台或销毁时停止并恢复箭头方向；系统关闭动画时使用静态图标。

修心关闭再次确认后，挑战完成在当前页面更新文字，不播放整页切换动画。按压按钮或单词题目显示完成文案，原主句、挑战内容、满格进度及退出按钮保留；完成后的挑战控件停止接受输入并保持原色。新增底部操作复用拦截按钮样式，与退出按钮间隔 8dp，使用 200ms 从下方 16dp 上浮，全程保持不透明。浮出期间不接受继续操作；切入后台时结束动画并保留完整按钮，页面恢复和系统关闭动画时直接显示完成状态。

拦截页面切换保持不透明，只沿垂直方向位移：旧画面移出后从绘制层移除，再显示并移入新页面，避免淡入淡出把实色按钮混成灰色。取消动画或页面恢复时显示完整的新页面；切换期间仍由原流程阻止重复操作。单词选项保留已有的按压缩放反馈。

拦截拖动滑块在有效行程达到 90% 后松手确认，允许松手点位于控件外，完成判定只检查拖动方向上的位置；松手时未达门槛（包括回拉到门槛以下）、取消及多指操作不执行。圆形滑块内三个小箭头以 1400ms 周期沿滑动方向依次轻微前移，提示可拖动方向，右到左布局同步镜像。按住滑块、禁用、隐藏、窗口失焦或控件移除时停止波浪；系统禁用动画时显示静态箭头。轨道使用对应的主题按钮表面，圆形滑块使用 `primary`、箭头使用 `on_primary`，两种轨道均保持清晰的局部操作提示，拖动时隐藏原引导文字。

页面样式在 XML 及共用资源维护，动态按钮由工厂应用同样的文字与背景资源。拦截按钮形状固定采用共用圆角。正式随心、修心首屏每次重新打开时独立重抽控件组合、位置及控件文案，原 Activity 从后台返回也按重新打开处理；本次显示的控件种子随系统状态保存，旋转或进程重建继续使用原组合。有主句的页面始终保留主句，同一规则当前这轮拦截保留已选正文，重新打开、后台返回及系统重建不更换；新规则会话首次显示对应页面时才从各类独立洗牌队列抽取，抽完重洗并避开上一轮末句。双退出和盲盒仍按原概率参与抽样；后台规则复查复用当前组合。关闭随心动态按钮后仍使用固定按钮，显式 Debug 预览使用可重复的样例且不推进正式主句队列。

拦截动态文案按普通主句、按压主句、单词风暴主句、数独完成语句、再次确认主句、单词选错及退出、继续使用、前往挑战、盲盒控件文案维护为十类 XML 数组。普通主句由提醒、限制和静心等场景共用，临时放行使用继续使用控件文案；单词题干、按压提示、按压和单词完成文字及读屏状态使用固定字符串模板，仅填入实际单词或数值。分类、资源位置及维护规则见[拦截文案库说明](拦截文案库说明.md)。

Markdown 以顶部 `date: YYYY-MM-DD` 表示维护日期，正文直接更新当前规范，不追加版本改动清单。修改资源时同步更新本文对应项；历史方案保存在 Git。

规则编辑器共用八张卡片、父卡点击反馈、12sp参数及既有深浅色资源。设置题量按实际词库容量更新按钮边界，主页条数在后台读取最近成功扫描的可管控应用数并在保存前复核；缺失、空或损坏快照不产生可保存条数。全部可填写范围与语义见[合法值参考表](合法值参考表.md)。当前静态扫描主资源47个布局，无直接重复 ID，13个输入容器均符合输入区域和下方提示的结构约定；源码及差异检查完成。未运行测试、编译、Lint 或设备视觉验证；窄屏、大字体、下方提示、键盘定位及主题切换仍需设备验收。

# 拦截文案库说明

拦截文案按展示位置与操作意图维护为十类动态库。普通拦截主句供提醒、限制及无为、修心、闭关共用；数独答题阶段没有主句，完成后显示独立完成语句；继续使用与临时放行共用控件文案。文案分类只决定显示文字，实际操作仍由设置和状态机执行。

## 固定文案与动态数据

其余提示使用单个 `<string>`，措辞保持固定；单词、题号、秒数、进度和操作名称按当前状态填入。

| 内容 | 资源与参数 | 维护文件 |
| --- | --- | --- |
| 按压前提示 | `interception_hold_idle_hint`：`%1$d` 为需要按住的秒数 | [interception_hold.xml](../app/src/main/res/values/interception_hold.xml) |
| 按压中提示 | `interception_hold_active_hint`：`%1$d` 为剩余秒数 | 同上 |
| 按压完成 | `interception_hold_completed`：按压已完成 | 同上 |
| 英译中题干 | `interception_word_prompt_en_zh`：选出“`%1$s`”的中文含义；参数为当前单词 | [interception_word.xml](../app/src/main/res/values/interception_word.xml) |
| 中译英题干 | `interception_word_prompt_zh_en`：选出“`%1$s`”的英文表达；参数为当前中文含义 | 同上 |
| 单词完成 | `interception_word_completed`：单词挑战已完成 | 同上 |
| 题号 | `interception_word_number`：`%1$d` 为当前题号，`%2$d` 为总题数 | 同上 |
| 单词停留读屏进度 | `interception_word_wait_progress`：`%1$d` 为百分比数值，`%%` 显示百分号 | 同上 |
| 休息秒数 | `interception_rest_seconds`：`%1$d` 为当前秒数 | [interception_status.xml](../app/src/main/res/values/interception_status.xml) |
| 滑动读屏说明 | `interception_slide_action`：`%1$s` 为选中的操作文案 | 同上 |

按压与单词完成后保留原主句、挑战内容和进度。数独完成后保留终盘，数字键退场、棋盘上移，再在按钮上方显示动态完成语句；继续操作仍等待用户主动点击。

## 维护方式

XML 使用四空格缩进，每个数组上方用中文注释说明用途。调整措辞时修改对应 `<item>`；换行使用 `\n`，`&` 和 `<` 按 XML 规则转义为 `&amp;` 和 `&lt;`，英文引号按 Android 字符串规则转义。固定模板保留原参数位置与类型，`%1$s` 表示文字，`%1$d` 表示整数。

[InterceptionCopyCatalog](../app/src/main/java/github/vhoom/zhijian/ui/interception/copy/InterceptionCopyCatalog.java) 的 `Pool` 是十类动态库的统一登记表。启动预加载校验库非空及固定题干、按压模板；各库可以独立增删条目，允许只保留一条。实际条数决定选句索引，页面之间共享已校验的只读资源缓存。

[ActionCopy](../app/src/main/java/github/vhoom/zhijian/ui/interception/copy/ActionCopy.java) 将操作去向适配到文案库，`CONTINUE` 与 `PASS` 都读取继续使用库。[PageAppearance](../app/src/main/java/github/vhoom/zhijian/ui/interception/page/support/PageAppearance.java) 显式区分正式规则会话与 Debug 样例；按压状态变化只更新固定提示，保留本次主句。[WordPage](../app/src/main/java/github/vhoom/zhijian/ui/interception/page/WordPage.java) 根据翻译方向读取固定题干，答错提示继续从单词选错库选句。

## 主句选择与恢复

普通、按压、单词风暴及再次确认四类主句各自随机洗牌，只有新规则会话首次显示对应页面时才消耗一条。每轮不同正文全部抽完再重洗；有其他正文时，新一轮首句避开上一轮末句。普通首屏和闭关共用普通队列，其他分类互不消耗。选择策略位于 [HeadlineRotation](../app/src/main/java/github/vhoom/zhijian/domain/interception/copy/HeadlineRotation.java)。

同一个规则当前这轮拦截的各类主句选定后保持不变。重新打开、后台返回、重复请求、按压状态变化及系统重建均复用原正文，控件的独立打开种子不参与主句选择。下一轮真实触发产生新的会话后，才从对应队列抽取新主句。

[InterceptionHeadlineStore](../app/src/main/java/github/vhoom/zhijian/data/store/interception/InterceptionHeadlineStore.java) 使用独立的 `interception_headlines` 偏好文件：`pool:` 条目保存资源清单、剩余队列与上次正文；`session:` 条目保存本轮各类已选正文。正文和队列通过同一编辑器 `apply()` 异步落盘，不修改 Room 或待处理会话格式。新选句时清理已经结束的会话缓存，保留当前会话及待处理存储中仍存在的展示、禁用和休息身份。资源增删或重排只重置对应库的队列，当前轮已显示的正文继续保留；损坏队列从当前资源重新初始化。

Debug 预览及独立页面样例继续按序号读取可重复的资源条目，不读写正式选句或队列。控件文案和单词答错提示沿用各自原有选择方式。

数独完成语句由 `PageAppearance.pickAttemptText()` 使用局身份 `attemptId` 和 `SUDOKU_COMPLETIONS` 分类计算稳定索引。正式局身份已经随机生成并保存，因此同一局重建或恢复继续显示相同语句，新局重新选句，允许不同局偶然选中同一句。此类文案不消耗规则主句队列，也不新增存储字段；预览使用固定局身份。旧的数独主句数组已移除。

动态文案、固定提示与页面样式分别维护；[interception_styles.xml](../app/src/main/res/values/interception_styles.xml) 负责样式。增删文案时同步本说明中的条数，资源名与分类保持一致。

# 本地诊断与问题反馈

## 日志范围

止间的 Debug 和 Release 均在应用启动时安装 DiagnosticLog。Debug 保留详细过程；Release 保留 INFO、WARN、ERROR，并将重复的正常检查按同类键最多每 30 秒采样一次。调试预览入口仍只在 Debug 开放。

记录包含 UTC 时间、设备单调时间、级别、模块、线程和相关会话标识。日志覆盖启动资源、无障碍连接、前台应用、有效规则来源与版本、阈值和实际用量、临时放行、待处理会话、页面请求、实际窗口回执和结果提交。普通字段内的换行转义；消息、堆栈及查看文本均有预算。

日志可能含被管控应用包名、使用量和规则阈值，仅在本机处理，不记录其他应用的文字、图片、输入内容、账号或设备唯一标识。应用没有日志上传任务、分析 SDK、广告 SDK 或新增网络权限。

## 保存与线程

专用私有目录为 files/diagnostics/，文件命名为 diagnostics-0.log、diagnostics-1.log、diagnostics-2.log。0 是当前文件，序号越大越旧。单个文件最多 512 KiB，总计最多 1.5 MiB；轮转保留最近文件，只淘汰最旧的一份。清空只删除这些固定名称的文件，不改变数据库和设置。

所有文件读写通过容量 256 的单线程队列；拥塞时不在调用线程写磁盘，丢弃数量在后续记录中说明。日志写入不影响规则判定和事务提交。未捕获异常尽力等待最多 400 ms 排空，再调用原异常处理器；强制结束进程、系统杀进程或队列拥塞仍可能丢失尚未写入的事件。

快照在此前事件写入后生成文件副本，因此轮转或清空不会破坏正在导出的快照。查看页面只渲染最近 64 Ki 个字符。导出任务由进程持有，页面重建不会重复提交。

## 拦截窗口确认

同一个 session 标识连接以下记录：

- evaluation/block：规则已命中，包含实际值与阈值。
- launch/requested：服务已调用页面启动入口。
- activity/request：页面已解析并装配会话。
- launch/window_confirmed：已装配的真实窗口获得焦点。
- launch/window_unconfirmed：目标仍相关且等待 5 秒后没有窗口回执。
- outcome：结果是否成功提交，失败时有堆栈。

startActivity 正常返回不能证明系统已显示页面。请求代次防止旧超时或其他会话回执干扰新请求；用户离开目标或服务解绑时取消等待。晚到的真实窗口回执会清除未确认状态。

未确认记录只说明失败边界，不直接断言某个品牌或权限是根因。引导会建议检查后台弹出界面、服务连接，并通过诊断记录区分页面初始化失败。无法统一检测的自启动与后台弹出界面保持“手动检查”，点击设置不等于授权完成。

## 手机内获取

设置 → 关于 → 诊断日志：刷新查看最近事件，点击导出，通过系统文件选择器保存 ZIP；也可清空本地诊断记录。Debug、Release 均提供此入口，不需要 root 或广泛存储权限。

导出文件名读取当前 `app_name`；ZIP 只包含 environment.txt 和 logs/ 下的固定诊断文件。环境说明包括应用版本、构建类型、Android 版本、机型、时区和权限开关，不导出数据库或全部使用历史。导出文件保存与后续分享由用户决定。

反馈时请同时描述发生时间、目标应用、规则配置、实际行为和期望行为。正式版堆栈需要开发者保存并使用对应构建的 app/build/outputs/mapping/release/mapping.txt 还原；mapping 不随 APK 发布、不提交 Git。

## 开发电脑获取

电脑通过 Android SDK 的 ADB 实时查看日志；诊断 ZIP 使用上面的手机内导出入口。当前仓库不提供一键采集脚本。

~~~powershell
adb logcat -v threadtime ZhijianDiagnostics:V ZhijianInterception:E ZhijianPermissions:W ZhijianUsage:V ZhijianExport:E ActivityTaskManager:I ActivityStarterImpl:D "*:S"
~~~

保持窗口运行，复现问题后用 Ctrl+C 停止。只筛选 package:github.vhoom.zhijian 会漏掉系统的后台启动拒绝，因为 ActivityTaskManager 等记录属于系统进程。

应用无法读取完整系统日志。窗口拒绝、系统杀进程等事件需开发者通过 ADB 查询；应用日志将保留窗口请求和缺少回执的证据，不能代替系统的具体拒绝原因。

## 验证

本地回归用例覆盖 Release 级别策略、消息预算、UTF-8 轮转、最近历史保留、快照隔离、清空范围、ZIP 实际内容、安全文件名，以及窗口回执的超时、取消、旧请求和晚到结果。分类清单见[本地单元测试](testing/本地单元测试.md)的诊断工具部分，实际页面导出链路见[设备测试](testing/设备测试.md)中的 `AboutDiagnosticsTest`。本次测试整理未运行测试、构建或 Lint，执行结果以实际报告为准。
